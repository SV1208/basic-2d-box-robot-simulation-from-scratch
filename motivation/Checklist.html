🔒 DAILY MICRO-CHECKLIST (30 DAYS)

Robotics / AI – Builder Mode

RULE ZERO (read every day)

If a step is skipped, the day is FAILED.

Partial completion = failure.

Quality does NOT matter. Completion does.

⏱️STEP 1 — START PROTOCOL (5 minutes)

You must do these in order, no thinking.

  • Sit at your desk
  • Open only: code editor OR notebook terminal / simulator (if needed)
  • Start a 90-minute timer
  • Write TODAY'S DATE at top of file / notebook

❌ If timer not started → cheating

❌ If date not written → cheating

🧭STEP 2 — DEFINE TODAY'S MICRO-GOAL (5 minutes max)

Write ONE sentence, nothing more:

"Today I will implement / modify __________."

Rules:

• Must produce new output

• Must be finishable today

• Must be specific

Examples (valid)

  • "Implement PID controller skeleton for motor"
  • "Code forward kinematics for 2-link arm"
  • "Train baseline model and log accuracy"
  • "Simulate obstacle avoidance logic"

Examples (invalid)

  • "Understand SLAM"
  • "Learn ROS"
  • "Improve project"
  • "Debug stuff"

❌ If goal > 1 sentence → cheating

❌ If vague → cheating

🧱STEP 3 — BUILD PHASE (70 minutes)

This is the core. No mercy.

Allowed actions

  • Writing new code
  • Modifying existing code
  • Writing equations
  • Running simulations
  • Testing and changing parameters
  • Making things slightly less broken

Forbidden actions

  • Watching videos
  • Reading tutorials
  • Browsing documentation for more than 5 minutes at a time
  • Refactoring for beauty
  • Planning future work
  • Rewriting notes

If stuck: You must still write something. Confusion is not an exception.

❌ No new file / change at end → cheating

❌ Only reading / watching → cheating

🧾STEP 4 — ARTIFACT CHECK (5 minutes)

At minute ~75:

You must have ONE tangible artifact:

  • .c / .cpp / .py file changed
  • Git commit
  • Simulation output
  • Math derivation page
  • Log file with results

Ask ONE question: "Can this be shown to another robotics/AI person?"

If no → day failed.

🧠STEP 5 — SINGLE LINE LOG (5 minutes)

Write exactly 2 lines, no more.

  • Line 1: What I built / changed today
  • Line 2: What is broken / unclear

No reflection. No emotion. No journaling.

This prevents fake productivity.

🛑STEP 6 — HARD STOP (0 minutes)

When timer ends:

  • Stop immediately
  • Even if "almost done"
  • Close editor

Stopping trains respect for limits.

❌ Continuing = cheating

❌ "Just 5 more minutes" = cheating

🚨CHEAT DETECTION (non-negotiable)

If ANY of these happened, the day is FAILED:

  • Timer not used
  • No new artifact
  • More consuming than building
  • Multiple goals
  • Changing task definition
  • Restarting timer
  • "I'll fix it tomorrow"

No excuses. Just mark FAILED and apply penalty.

📆WHAT CHANGES DAY TO DAY?

Only ONE thing: the micro-goal

Everything else stays identical for 30 days.

No optimization. No tweaking. No redesign.

🧠WHY THIS WORKS (very briefly)

  • Removes choice
  • Removes identity games
  • Forces contact with reality
  • Makes cheating obvious
  • Builds compounding artifacts
  • Trains showing up, not motivation

FINAL LOCK

For the next 30 days, you are not:

  • "learning robotics"
  • "preparing for AI career"

You are:

Someone who builds one small, real thing every day without negotiation.
